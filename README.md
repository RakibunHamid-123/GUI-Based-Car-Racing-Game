Description: A simple and interactive Java car racing game where the player controls a car to avoid enemy cars and survive as long as possible. The game includes road animation, sound effects, score counting, timer system, and restart functionality. The objective of the project is to practice Java GUI programming, graphics, animation, event handling, and game logic implementation.

Features: Smooth car movement, random enemy car generation, moving road animation, score counting system, timer display, sound effects, keyboard controls, game over system, restart system, and interactive colorful GUI design.

Week 2: Project Architecture & Environment Setup Development began with establishing the underlying class hierarchy and initializing the primary application window. The foundational class structure was configured within the NetBeans IDE by extending Java Swing’s JPanel and implementing the initial window setup using JFrame. This stage established the rendering canvas dimensions (600×700 pixels), set up the event-dispatching thread via SwingUtilities.invokeLater(), and planned the core layout necessary for hosting interactive game components. 
Week 3: Graphics & Static Vector Rendering The user interface graphics were implemented within paintComponent(Graphics g) using Graphics2D vector drawing techniques. The visual environment was split into distinct regions: a central dark gray driving track bounded by solid white margins, surrounded by green grass terrain. Additionally, custom vehicle rendering logic was introduced, drawing both player and enemy cars complete with rounded rectangular bodies, glass windshields, wheels, yellow headlights, and red tail lights. 
Weeks 4 & 5: Player Controls & Dynamic Road Physics Interactive movement and motion physics were introduced using Java’s KeyListener and dynamic coordinate updates. Player movement was bounded strictly between the left and right road margins using keyboard arrow listener events (VK_LEFT and VK_RIGHT). Concurrently, vertical coordinate offsets were applied to animate the downward scrolling of yellow central lane dividers, while an autonomous enemy car movement loop was built using java.util.Random to dynamically spawn obstacles at varying horizontal road positions. 
Weeks 6 & 7: Game Loop, Scoring & Collision Physics A real-time game loop running at ~60 FPS (16ms interval) was established using javax.swing.Timer to handle state updates continuously. A frame-counting system was added to track real-time survival duration alongside an automated scoring system that awards points every time an enemy car successfully navigates past the bottom of the screen. Bounding-box collision detection was integrated using java.awt.Rectangle.intersects(), which instantly freezes game updates upon vehicle impact and triggers a dedicated Game Over overlay. 
Week 8: Java Sound API & Audio Engine Audio effects were fully embedded into the execution cycle using javax.sound.sampled audio streams and .wav classpath assets. The sound engine managed four distinct clips: continuous background loops for the main menu (welcome.wav) and engine running state (run.wav), alongside triggered single-shot effects for earning points (score.wav) and colliding with obstacles (crash.wav). Exception handling and resource stream validation were incorporated to ensure cross-platform audio stability. 
Week 9: Finite State Machine, UI Polish & System Restart The game reached full completion through a state-driven architecture managed by boolean flags (isWelcomeScreen and isGameOver). A specialized Welcome Screen was implemented, rendering centered title banners, preview car graphics, and keybindings. Pressing ENTER seamlessly transitions the application from the menu state into active gameplay while managing audio transitions, and pressing R following a collision resets all spatial variables, timers, and game states to allow instant restarts.
